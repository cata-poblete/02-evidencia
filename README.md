# Why we love boring technology

Las reglas tributarias de los países donde operamos cambian más rápido que cualquier stack de moda. Elegimos herramientas maduras para que la complejidad viva en el dominio, no en la infraestructura.

## Stack Tecnológico 
`Ruby on Rails` `PostgreSQL` `TypeScript` `PHP` `Kubernetes`

## Cómo está armado

*   **Monolito Rails:** Core de nómina.
*   **Microservicios:** Dominios específicos.
*   **AWS multi-región:** Para absorber los picos de cierre de mes.

En el frontend, operamos con monorepos con librerías de componentes centralizadas para mantener un tipado estricto y orden entre múltiples productos.

## Cómo desplegamos

*   **CI/CD** con alta cobertura de pruebas automatizadas.
*   **Feature flags** para desacoplar el deploy del lanzamiento comercial.
*   **Blameless post-mortems** enfocados en el aprendizaje sistémico (Cultura de error).
